This directory contains the Astro 7.4 + Starlight 0.42 documentation frontend, Pagefind search pipeline, `<VoxPlayground />` interactive evaluator, and Playwright audit suite for **[voxlang.org](https://voxlang.org)**.

For the complete architecture tour, compiler-verified doctest pipeline, W3C SKOS taxonomy contract, `/v1/eval` sandbox specification, and build commands, see the repository root [**`README.md`**](../README.md).
